<div class="note">
  <p><strong>Note:</strong> The <code>AuroElement</code> base class doesn't handle keyboard events. It's a superclass extending <code>LitElement</code> that manages layout, shape, and size CSS classes for components such as <code>&lt;auro-input&gt;</code> and <code>&lt;auro-dropdown&gt;</code>.</p>
