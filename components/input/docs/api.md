# auro-input

The `auro-input` element provides users a way to enter data into a text field.

## Properties

| Property                           | Attribute                          | Modifiers | Type                                             | Default     | Description                                      |
|------------------------------------|------------------------------------|-----------|--------------------------------------------------|-------------|--------------------------------------------------|
| `a11yActivedescendant`             | `a11yactivedescendant`             |           | `string`                                         |             | Sets the ID of the option screen readers announce as active while focus stays in the input,<br />such as the highlighted option in a list (the inner `<input>` element's `aria-activedescendant`). |
| `a11yControls`                     | `a11ycontrols`                     |           | `string`                                         |             | Sets the ID of the element the input controls, such as a combobox's list of options<br />(the inner `<input>` element's `aria-controls`). |
| `a11yExpanded`                     | `a11yexpanded`                     |           | `boolean`                                        |             | Tells screen readers that the element the input controls, such as a list of options, is open<br />(the inner `<input>` element's `aria-expanded`). |
| `a11yRole`                         | `a11yrole`                         |           | `string`                                         |             | Sets the role screen readers announce for the inner `<input>` element, such as `combobox`<br />when the input is part of `auro-combobox` (the input's `role`). |
| `activeLabel`                      | `activelabel`                      |           | `boolean`                                        | false       | Keeps the label raised above the value, even when the field is empty and doesn't have focus.<br />Applies only to the `classic` layout; the emphasized and snowflake layouts always show the label inside the field. |
| `appearance`                       | `appearance`                       |           | `'default' \| 'inverse'`                         | "'default'" | Sets the color scheme. Use `inverse` on dark backgrounds and `default` on light backgrounds. |
| `autocapitalize`                   | `autocapitalize`                   |           | `'off' \| 'none' \| 'on' \| 'sentences' \| 'words' \| 'characters'` |             | Sets whether mobile keyboards capitalize text as the user types, such as `words` for names<br />(the input's `autocapitalize`). Does not currently apply: the input clears this value on every<br />update, unless `spellcheck="false"`, which sets it to `none`. |
| `autocomplete`                     | `autocomplete`                     |           | `string`                                         |             | Sets what the browser can suggest when filling in the field, such as `off` to turn off<br />autofill suggestions (the input's `autocomplete`). Only `autocomplete="off"` is currently supported. |
| `autocorrect`                      | `autocorrect`                      |           | `'on' \| 'off'`                                  |             | Sets whether Safari on iOS corrects words as the user types. Use `off` for names, codes, and<br />other text that isn't made of dictionary words. Always `off` when `spellcheck="false"`. |
| `customValidityTypeEmail`          | `customvaliditytypeemail`          |           | `string`                                         |             | Does not currently change any message. To set the error message for an invalid email address,<br />use `setCustomValidityForType`. |
| `disabled`                         | `disabled`                         |           | `boolean`                                        | false       | Turns the input off. A disabled input is shown in a muted style, can't be edited or reached<br />with the keyboard, and doesn't show the clear button. |
| `dvInputOnly`                      | `dvinputonly`                      |           | `boolean`                                        | false       | Keeps the label visible while `displayValue` slot content is shown in place of the value.<br />Without it, the `displayValue` content hides both the label and the value. |
| `error`                            | `error`                            |           | `string`                                         |             | Shows an error that stays until you remove the attribute, and sets `validity` to `customError`.<br />The attribute value is the error message, unless `setCustomValidityCustomError` or `setCustomValidity` is set. |
| `errorMessage`                     | `errormessage`                     |           | `string`                                         |             | Holds the error message shown below the field for the current `validity`.<br />Validation sets it, so read it instead of setting it. |
| `format`                           | `format`                           |           | `string`                                         |             | Sets the pattern the value is formatted to as the user types, such as `mm/dd/yyyy` for a date or<br />`+1 (000) 000-0000` for a phone number. Outside dates, `0` stands for a digit, `a` for a letter, and `*` for any character.<br />For `type="date"`, it replaces the format that `locale` would set. |
| `hasFocus`                         |                                    |           | `boolean`                                        |             | Reports whether the input currently has focus. The input updates it, so read it instead of setting it. |
| `hasValue`                         |                                    |           | `boolean`                                        | false       | Reports whether the input currently has a value. The input updates it, so read it instead of setting it. |
| `icon`                             | `icon`                             |           | `boolean`                                        | false       | Shows a card icon left of the value that changes to the detected card brand, such as Visa, as the user types.<br />Applies only when `type="credit-card"`. |
| `id`                               | `id`                               |           | `string`                                         |             | Sets a unique ID for the element, such as `email`. The inner `<input>` element uses this ID<br />followed by `-input`, such as `email-input`. |
| `inputmode`                        | `inputmode`                        |           | `string`                                         |             | Sets which on-screen keyboard mobile devices show, such as `numeric` for digits only or `email`<br />(the input's `inputmode`). Defaults to `numeric` when `type` is `number`, `tel`, `credit-card`, or `date`. |
| `lang`                             | `lang`                             |           | `string`                                         |             | Sets the language of the input's built-in help text and error messages, such as `es` for Spanish.<br />Only `es` changes the text; other values use English. When not set, the input follows the page's `lang`. |
| `layout`                           | `layout`                           |           | `'classic' \| 'emphasized' \| 'emphasized-left' \| 'emphasized-right' \| 'snowflake' \| 'snowflake-left' \| 'snowflake-right'` | "'classic'" | Sets how the label and value are arranged. `classic` raises the label above the value<br />when the field has focus or a value; the `emphasized` and `snowflake` layouts always show the label inside the field. |
| `locale`                           | `locale`                           |           | `string`                                         | "en-US"     | Sets the region whose date format `type="date"` uses, such as `en-GB` for `dd/mm/yyyy`.<br />When not set, the input uses the nearest ancestor's `data-locale` attribute, or `en-US`. |
| `max`                              | `max`                              |           | `string`                                         | "undefined" | Sets the largest value allowed, such as `10` for a number or `2025-12-31` for a date.<br />Applies only when `type` is `number`, or `date` with a full date format; write dates in ISO format (`YYYY-MM-DD`). |
| `maxLength`                        | `maxlength`                        |           | `number`                                         | "undefined" | Sets the most characters the user can enter, as a whole number `0` or higher.<br />Don't set it when `type` is `credit-card`, `tel`, or `date`, because those types set their own length. |
| `maxObject`                        |                                    | readonly  | `Date \| undefined`                              |             | Gets `max` as a `Date` object, or `undefined` when `max` isn't a valid ISO date (`YYYY-MM-DD`). |
| `min`                              | `min`                              |           | `string`                                         | "undefined" | Sets the smallest value allowed, such as `1` for a number or `2024-01-01` for a date.<br />Applies only when `type` is `number`, or `date` with a full date format; write dates in ISO format (`YYYY-MM-DD`). |
| `minLength`                        | `minlength`                        |           | `number`                                         | "undefined" | Sets the fewest characters the value needs to be valid, as a whole number no larger than `maxlength`.<br />An empty value isn't checked against it; use `required` for that. |
| `minObject`                        |                                    | readonly  | `Date \| undefined`                              |             | Gets `min` as a `Date` object, or `undefined` when `min` isn't a valid ISO date (`YYYY-MM-DD`). |
| `name`                             | `name`                             |           | `string`                                         |             | Sets the field name `auro-form` uses for this input's value, such as `email`<br />(the inner `<input>` element's `name`). |
| `nested`                           | `nested`                           |           | `boolean`                                        |             | Marks the input as placed inside another component, such as the trigger of `auro-dropdown`.<br />Does not currently change how the input looks or behaves; use `simple` to remove the border. |
| `noValidate`                       | `novalidate`                       |           | `boolean`                                        | false       | Turns off validation when the input loses focus. Validation still runs when code sets the value<br />or when `validateOnInput` is set. |
| `onDark`                           | `ondark`                           |           | `boolean`                                        | false       | Deprecated: Use `appearance="inverse"` instead.<br />Styles the input for a dark background. |
| `pattern`                          | `pattern`                          |           | `string`                                         |             | Sets a regular expression the whole value must match to be valid, such as `[a-z]{1,15}`<br />(the input's `pattern`). Use `setCustomValidityPatternMismatch` to set the error message. |
| `placeholder`                      | `placeholder`                      |           | `string`                                         |             | Sets hint text shown in the empty field, such as `John Doe`.<br />When not set and `type="date"`, the input shows the date format, such as `MM/DD/YYYY`. |
| `readonly`                         | `readonly`                         |           | `boolean`                                        |             | Stops the user from editing the value, while code can still set it.<br />A read-only input can still get focus, and doesn't show the clear button. |
| `required`                         | `required`                         |           | `boolean`                                        | false       | Makes the input invalid when it's left empty, and removes the " (optional)" text after the label.<br />Use `setCustomValidityValueMissing` to set the error message. |
| `setCustomValidity`                | `setcustomvalidity`                |           | `string`                                         |             | Sets one error message for every kind of validation error. When set, it replaces the messages from<br />`error` and every other `setCustomValidity*` property. |
| `setCustomValidityBadInput`        | `setcustomvaliditybadinput`        |           | `string`                                         |             | Sets the error message for `validity="badInput"`. Does not currently change any message,<br />because the input never reports `badInput`. |
| `setCustomValidityCustomError`     | `setcustomvaliditycustomerror`     |           | `string`                                         |             | Sets the error message shown while the `error` attribute is set, in place of the `error` value. |
| `setCustomValidityForType`         | `setcustomvalidityfortype`         |           | `string`                                         | "undefined" | Sets the error message shown when the value doesn't fit its `type`, such as a badly formed email address,<br />an incomplete card number, or an incomplete date. When not set, `email`, `credit-card`, and most `date` inputs use a built-in message. |
| `setCustomValidityPatternMismatch` | `setcustomvaliditypatternmismatch` |           | `string`                                         |             | Sets the error message shown when the value doesn't match `pattern`, or when a date isn't a real calendar date.<br />For `pattern`, it does not currently work when set only as a property, so set the attribute instead. |
| `setCustomValidityRangeOverflow`   | `setcustomvalidityrangeoverflow`   |           | `string`                                         |             | Sets the error message shown when the value is above `max`. |
| `setCustomValidityRangeUnderflow`  | `setcustomvalidityrangeunderflow`  |           | `string`                                         |             | Sets the error message shown when the value is below `min`. |
| `setCustomValidityTooLong`         | `setcustomvaliditytoolong`         |           | `string`                                         |             | Sets the error message shown when the value is longer than `maxlength`.<br />Does not currently work when set only as a property, so set the attribute instead. |
| `setCustomValidityTooShort`        | `setcustomvaliditytooshort`        |           | `string`                                         |             | Sets the error message shown when the value is shorter than `minlength`.<br />Does not currently work when set only as a property, so set the attribute instead. |
| `setCustomValidityValueMissing`    | `setcustomvalidityvaluemissing`    |           | `string`                                         |             | Sets the error message shown when a `required` input is left empty. |
| `shape`                            | `shape`                            |           | `'box' \| 'classic' \| 'pill' \| 'pill-left' \| 'pill-right' \| 'rounded' \| 'snowflake'` | "'classic'" | Sets the shape of the field's border. The emphasized layouts support `pill`, `pill-left`,<br />and `pill-right`, and the snowflake layout uses `snowflake`. |
| `simple`                           | `simple`                           |           | `boolean`                                        |             | Removes the field's border and background, such as for an input placed inside another component. |
| `size`                             | `size`                             |           | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`           | "'lg'"      | Sets the field's size. The `classic` shape is the same height at every size, and the<br />emphasized layouts support only `xl`. |
| `spellcheck`                       | `spellcheck`                       |           | `'true' \| 'false'`                              |             | Sets whether the browser checks the value for spelling mistakes (the input's `spellcheck`).<br />Use `false` for codes, names, and other text that isn't made of dictionary words; it also sets `autocorrect` to `off`<br />and `autocapitalize` to `none`. Password inputs always use `false`. |
| `type`                             | `type`                             |           | `'text' \| 'password' \| 'email' \| 'credit-card' \| 'tel' \| 'number' \| 'date'` | "'text'"    | Sets the kind of value the input expects, which controls its formatting, validation, and mobile keyboard.<br />`credit-card`, `tel`, and `date` format the value as the user types, and `password` hides the text and adds a show/hide button.<br />The show/hide button appears only in the `classic` layout. |
| `validateOnInput`                  | `validateoninput`                  |           | `boolean`                                        |             | Validates the value as the user types, instead of waiting until the input loses focus.<br />Use it with `pattern` when the user needs feedback before leaving the field. |
| `validity`                         | `validity`                         |           | `string`                                         |             | Reports the result of the last validation, such as `valid`, `valueMissing`, or `patternMismatch`.<br />Validation sets it, so read it instead of setting it. |
| `value`                            | `value`                            |           | `string`                                         | "undefined" | Sets or gets the input's current value. For `type="date"` with a full date format, the value is an ISO date,<br />such as `2025-12-31`, whatever format the user sees; partial formats, such as `mm/yy`, use the text shown in the field. |
| `valueObject`                      |                                    | readonly  | `Date \| undefined`                              |             | Gets `value` as a `Date` object, or `undefined` when `value` isn't a valid ISO date (`YYYY-MM-DD`). |

## Methods

| Method     | Type                                   | Description                                      |
|------------|----------------------------------------|--------------------------------------------------|
| `clear`    | `(): void`                             | Clears the value. Unlike `reset()`, it doesn't clear the touched state, so a `required` input the user has already interacted with can show its error. |
| `focus`    | `(): void`                             | Moves focus to the input.                        |
| `reset`    | `(): void`                             | Resets the input to its initial state: clears the value, the touched state, and `validity`. |
| `validate` | `(force?: boolean \| undefined): void` | Checks the value against the input's validation rules and updates `validity` and `errorMessage`.<br /><br />**force**: If true, validates even while the input has focus or before the user has interacted with it. If false, validates only when `validateOnInput` is set, or when the input doesn't have focus and has been interacted with or has a value. |

## Events

| Event                       | Type               | Description                                      |
|-----------------------------|--------------------|--------------------------------------------------|
| `auroFormElement-validated` |                    | Fires each time the input is validated, with the result in `event.detail.validity` and `event.detail.message`. |
| `auroInput-validityChange`  | `CustomEvent<any>` | Fires when `validity` changes.                   |
| `input`                     | `InputEvent`       | Fires when the value changes, whether the user types or code sets the value. Events from code changes have `isProgrammatic` set to `true`. |

## Slots

| Name                      | Description                                      |
|---------------------------|--------------------------------------------------|
| `ariaLabel.clear`         | Text screen readers announce for the clear button, for example "Clear full name". Defaults to "Clear Input". {@category a11y} |
| `ariaLabel.password.hide` | Text screen readers announce for the button that hides the password, for example "Hide password". Defaults to "Hide Password". {@category a11y} |
| `ariaLabel.password.show` | Text screen readers announce for the button that shows the password, for example "Show password". Defaults to "Show Password". {@category a11y} |
| `displayValue`            | Content shown in place of the value when the input has a value and doesn't have focus, such as a city name for an airport code. It also hides the label unless `dvInputOnly` is set. {@category ui} |
| `helpText`                | Help text shown below the field, such as a hint about what to enter. An error message replaces it while the input is invalid. When the slot is empty, `password`, `email`, `credit-card`, and `tel` inputs show built-in help text. {@category ui} |
| `label`                   | The field's label, which screen readers also announce as the field's name. {@requiredWhen always} {@category ui} |
| `optionalLabel`           | Text shown after the label when the input isn't `required`, in place of the default " (optional)". To show nothing, put an empty element in the slot, such as `<span slot="optionalLabel"></span>`. {@relevantWhen !required} {@category ui} |

## CSS Shadow Parts

| Part            | Description                                      |
|-----------------|--------------------------------------------------|
| `accent-left`   | The area left of the value that holds `accentIcon`. Rendered only in the `classic` layout. |
| `accent-right`  | The area right of the value that holds the error icon, the show/hide password button, and the clear button. Rendered only in the `classic` layout. |
| `accentIcon`    | The icon left of the value: the card icon when `icon` is set with `type="credit-card"`, or the calendar icon when `type="date"`. Not rendered in the emphasized layouts. |
| `displayValue`  | The element that holds the `displayValue` slot content. |
| `helpText`      | The `<p>` element that holds the help text or error message. |
| `input`         | The inner `<input>` element.                     |
| `inputHelpText` | The area below the field that holds the help text or error message. |
| `label`         | The `<label>` element that holds the `label` slot. |
| `wrapper`       | The field's outer box, which holds the label, value, and icons but not the help text. |
