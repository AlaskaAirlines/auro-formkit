# auro-select

A form control that lets people choose one option, or several, from a list, such as a sort order or a destination airport.

**Key capabilities**
- **Multiple selection**: Set `multiSelect` to let people choose more than one option.
- **Validation**: Set `required` to require a selection, and `setCustomValidity` to change the error message.
- **Fullscreen on small screens**: Set `fullscreenBreakpoint` to choose the largest screen size at which the list opens as a fullscreen dialog.
- **Type-ahead**: Typing moves to the first available option whose text starts with the typed characters and opens the list; repeating a letter cycles through the options that start with it.
- **Layouts**: Set `layout` to `classic`, `emphasized`, or `snowflake` to change the overall look.

**Example**

```html
<auro-select>
  <span slot="label">Sort by</span>
  <auro-menu>
    <auro-menuoption value="price">Price</auro-menuoption>
    <auro-menuoption value="duration">Duration</auro-menuoption>
  </auro-menu>
</auro-select>
```

### Events

| Name                      | Description                                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| auroFormElement-validated | Fires each time the select validates, with the current `validity` and error `message` in `event.detail`. |
| auroSelect-valueSet       | Fires whenever `value` changes. Use `input` in new code, which also includes the new value.              |
| input                     | Fires whenever `value` changes, with the new `value` and `optionSelected` in `event.detail`.             |

### Slots

| Name                    | Category | Required | Relevant when | Description                                                                                                                                                                                                                                |
| ----------------------- | -------- | -------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| (default)               | ui       | Yes      |               | The `<auro-menu>` that holds the options.                                                                                                                                                                                                  |
| bib.fullscreen.headline | ui       | Yes      |               | Headline shown above the options in the fullscreen bib, such as "Sort by".                                                                                                                                                                 |
| displayValue            | ui       |          |               | Content shown in the trigger in place of the selected option's text while the bib is closed, such as an icon. Put it inside each `<auro-menuoption>` with `slot="displayValue"`, and the select copies the selected option's content here. |
| helpText                | ui       |          |               | Help text shown below the select. An error message replaces it while the select is invalid.                                                                                                                                                |
| label                   | ui       | Yes      |               | Label that names the select. | optionalLabel           | ui       |          | `!required`   | Text shown after the label when `required` isn't set, such as a translated "(optional)". Defaults to "(optional)".                                                                                                                         |
| valueText               | ui       |          |               | Doesn't currently show its content. To change how the selected value looks, use the `displayValue` slot instead.                                                                                                                           |
| ariaLabel.bib.close     | a11y     | Yes      |               | Text screen readers announce for the close button in the fullscreen bib, such as "Close sort options". Defaults to "Close".                                                                                                                |

### CSS shadow parts

| Name            | Description                                                                                                                                                                                                                                               |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| displayValue    | The container for `displayValue` content in the trigger.                                                                                                                                                                                                  |
| dropdown        | The inner dropdown element that holds the trigger and the bib.                                                                                                                                                                                            |
| dropdownChevron | The container for the arrow icon that shows whether the bib is open.                                                                                                                                                                                      |
| dropdownSize    | A hidden element whose `height`, `width`, `max-height`, and `max-width` are copied to the bib. Applies only when the bib matches the trigger's width: in the classic layout unless `flexMenuWidth` is set, and in other layouts when `matchWidth` is set. |
| dropdownTrigger | The trigger that shows the label and selected value. Doesn't currently match any element, so styles set on it have no effect.                                                                                                                             |
| helpText        | The help text or error message shown below the select.                                                                                                                                                                                                    |
| wrapper         | The outermost element inside the select.                                                                                                                                                                                                                  |
