# auro-combobox

The `auro-combobox` element provides users with a way to select an option from a list of filtered or suggested options based on user input.

## Properties

| Property                              | Attribute                             | Modifiers | Type                                             | Default          | Description                                      |
|---------------------------------------|---------------------------------------|-----------|--------------------------------------------------|------------------|--------------------------------------------------|
| `appearance`                          | `appearance`                          |           | `'default' \| 'inverse'`                         | "'default'"      | Sets the colors for the background the combobox sits on.<br />Use `inverse` on dark backgrounds and `default` everywhere else. |
| `autoPlacement`                       | `autoplacement`                       |           | `boolean`                                        |                  | Deprecated: Use `placement` instead.<br />Moves the bib to whichever side of the trigger has the most space.<br />The bib already flips to the opposite side when it doesn't fit, unless `noFlip` is set. |
| `autocomplete`                        | `autocomplete`                        |           | `string`                                         |                  | Sets what the browser can suggest when filling in the field, such as `off` to turn off<br />autofill suggestions (the input's `autocomplete`). Only `autocomplete="off"` is currently supported. |
| `behavior`                            | `behavior`                            |           | `'filter' \| 'suggestion'`                       | "'suggestion'"   | Sets whether the combobox accepts typed text that isn't one of the options. Use `suggestion` (the default) when people<br />can enter their own value, and `filter` when they must choose an option from the menu.<br />In `filter` mode, typed text that doesn't match a chosen option fails validation, even when `required` isn't set. |
| `checkmark`                           | `checkmark`                           |           | `boolean`                                        |                  | Shows a check mark next to the selected option in the menu. |
| `disabled`                            | `disabled`                            |           | `boolean`                                        |                  | Turns the combobox off. A disabled combobox is shown in a muted style, and its input<br />can't be edited or reached with the keyboard. |
| `dvInputOnly`                         | `dvinputonly`                         |           | `boolean`                                        |                  | Keeps the label visible while `displayValue` content is shown in place of the value.<br />Without it, the `displayValue` content hides both the label and the value. |
| `error`                               | `error`                               |           | `string`                                         |                  | Shows an error that stays until you remove the attribute, and sets `validity` to `customError`.<br />The attribute value is the error message, unless `setCustomValidityCustomError` or `setCustomValidity` is set. |
| `format`                              | `format`                              |           | `string`                                         |                  | Sets the pattern the value is formatted to as the user types, such as `mm/dd/yyyy` for a date.<br />Does not currently apply to the trigger input, only to the input in the fullscreen bib. |
| `fullscreenBreakpoint`                | `fullscreenbreakpoint`                |           | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'disabled'` | "'sm'"           | Sets the screen width, such as `sm`, at or below which the open bib fills the screen as a modal dialog.<br />Use `disabled` to keep the bib from ever going fullscreen. |
| `inputValue`                          |                                       | readonly  | `string \| undefined`                            |                  | Gets the text currently in the input, which changes as the user types. |
| `inputmode`                           | `inputmode`                           |           | `string`                                         |                  | Sets which on-screen keyboard mobile devices show, such as `numeric` for digits only<br />(the input's `inputmode`). Defaults to `numeric` when `type` is `number`, `tel`, `credit-card`, or `date`. |
| `largeFullscreenHeadline`             | `largefullscreenheadline`             |           | `boolean`                                        |                  | Shows the `bib.fullscreen.headline` text in a larger heading style. Applies only when the bib is fullscreen. |
| `layout`                              | `layout`                              |           | `'classic' \| 'emphasized' \| 'snowflake'`       | "'classic'"      | Sets the overall style of the combobox. The `emphasized` layout also shows larger menu options. |
| `noFilter`                            | `nofilter`                            |           | `boolean`                                        |                  | Shows every option whatever the user types, instead of hiding options that don't match.<br />Use it when your code replaces the options as the user types, such as with results from a server. |
| `noFlip`                              | `noflip`                              |           | `boolean`                                        |                  | Keeps the bib at its `placement` when there isn't enough space, instead of flipping it to the opposite side. |
| `noValidate`                          | `novalidate`                          |           | `boolean`                                        |                  | Turns off validation when focus leaves the combobox, and when its value changes while it doesn't have focus.<br />Setting `error` or calling `validate()` still validates. |
| `offset`                              | `offset`                              |           | `number`                                         | "0"              | Sets the gap between the trigger and the bib in pixels, such as `8`. |
| `onDark`                              | `ondark`                              |           | `boolean`                                        |                  | Deprecated: Use `appearance="inverse"` instead.<br />Styles the combobox for a dark background. |
| `optionSelected`                      |                                       |           | `HTMLElement`                                    |                  | Holds the selected `<auro-menuoption>` element, or `undefined` when no option is selected.<br />The combobox updates it, so read it instead of setting it. |
| `persistInput`                        | `persistinput`                        |           | `boolean`                                        |                  | Keeps the typed text in the input when the user chooses an option, so the menu stays filtered<br />and they can choose again from the same results. Use it with the `displayValue` slot to show<br />the chosen option while the combobox doesn't have focus. |
| `placeholder`                         | `placeholder`                         |           | `string`                                         |                  | Sets hint text shown in the empty input, such as `Search airports`.<br />When not set and `type="date"`, the input shows the date format, such as `MM/DD/YYYY`. |
| `placement`                           | `placement`                           |           | `'top' \| 'right' \| 'bottom' \| 'left' \| 'bottom-start' \| 'top-start' \| 'top-end' \| 'right-start' \| 'right-end' \| 'bottom-end' \| 'left-start' \| 'left-end'` | "'bottom-start'" | Sets where the bib opens relative to the trigger, such as `bottom-start` for below the trigger, lined up with its start edge.<br />The bib flips to the opposite side when there isn't room, unless `noFlip` is set. |
| `required`                            | `required`                            |           | `boolean`                                        |                  | Makes the combobox invalid when it's left empty, and removes the "(optional)" text after the label.<br />Use `setCustomValidityValueMissing` to set the error message. |
| `setCustomValidity`                   | `setcustomvalidity`                   |           | `string`                                         |                  | Sets one error message for every kind of validation error. When set, it replaces the messages from `error`<br />and every other `setCustomValidity*` property, except `setCustomValidityValueMissingFilter`. |
| `setCustomValidityCustomError`        | `setcustomvaliditycustomerror`        |           | `string`                                         |                  | Sets the error message shown while the `error` attribute is set, in place of the `error` value. |
| `setCustomValidityValueMissing`       | `setcustomvalidityvaluemissing`       |           | `string`                                         |                  | Sets the error message shown when a `required` combobox is left empty. |
| `setCustomValidityValueMissingFilter` | `setcustomvalidityvaluemissingfilter` |           | `string`                                         |                  | Sets the error message shown in `filter` mode when the typed text doesn't match a chosen option.<br />Set it as an attribute: setting only the property doesn't currently change the message. |
| `shape`                               | `shape`                               |           | `'box' \| 'classic' \| 'pill' \| 'pill-left' \| 'pill-right' \| 'rounded' \| 'snowflake'` | "'classic'"      | Sets the shape of the trigger. In the `snowflake` layout, the menu options use the same shape<br />unless the `<auro-menu>` sets its own `shape`. |
| `shift`                               | `shift`                               |           | `boolean`                                        |                  | Slides the bib along the trigger's edge to keep it inside the viewport. |
| `size`                                | `size`                                |           | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`           | "'xl'"           | Sets the height of the trigger. The menu options don't follow it: they use `lg` in the<br />`emphasized` layout and `md` otherwise. |
| `triggerIcon`                         | `triggericon`                         |           | `boolean`                                        |                  | Shows a card icon in the input that changes to the detected card brand, such as Visa, as the user types.<br />Applies only when `type="credit-card"`. |
| `type`                                | `type`                                |           | `'text' \| 'password' \| 'email' \| 'credit-card' \| 'tel' \| 'number' \| 'date'` |                  | Sets the kind of value the input expects, which controls its formatting, validation, and mobile keyboard.<br />`credit-card`, `tel`, and `date` format the value as the user types, and `password` hides the text.<br />Uses auro-input's default, `text`, when not set. |
| `typedValue`                          | `typedvalue`                          |           | `string`                                         |                  | Sets the text in the input, such as a search the user started earlier.<br />It doesn't change as the user types, so read `inputValue` for the current text. |
| `validity`                            | `validity`                            |           | `string`                                         |                  | Reports the result of the last validation, such as `valid`, `valueMissing`, or `customError`.<br />Validation sets it, so read it instead of setting it. |
| `value`                               | `value`                               |           | `string`                                         |                  | Sets or gets the combobox's value: the chosen option's `value`, or the text in the input when no option is chosen.<br />A value that matches a `disabled` or `static` option is rejected, which clears `value` and `optionSelected` to `undefined`.<br />A value that matches a `hidden` option, such as one filtered out by typing, still selects it. |

## Methods

| Method               | Type                                   | Description                                      |
|----------------------|----------------------------------------|--------------------------------------------------|
| `clear`              | `(): void`                             | Clears the value, the input text, and the selected option.<br />Doesn't clear the validation state; use `reset()` for that. |
| `focus`              | `(): void`                             | Moves focus to the input, unless focus is already inside the combobox. |
| `hideBib`            | `(): void`                             | Closes the bib if it's open.                     |
| `isValid`            | `(): boolean`                          | Checks whether the combobox passed its last validation. |
| `reset`              | `(): void`                             | Clears the value, the input text, and the selected option, and clears the validation state,<br />so no error shows until the combobox validates again. |
| `setMenuValue`       | `(value: string): void`                | Selects the menu option whose `value` matches. Does nothing when there's no menu or the menu already has that value;<br />when no option can be selected, it clears `value` and `optionSelected` to `undefined`.<br /><br />**value**: The `value` of the option to select. |
| `showBib`            | `(): void`                             | Opens the bib when the input has text and there's something to show: matching options, a `nomatch` option, or a loading menu.<br />When the menu is loading without `loadingText` or `loadingIcon` content, the bib opens once loading ends, if focus is still in the combobox. |
| `updateActiveOption` | `(index: number): void`                | Sets the active (highlighted) option to the one at `index` among the options currently shown.<br />Does nothing when no shown option is at that position.<br /><br />**index**: The position of the option among the options currently shown, starting at 0. |
| `validate`           | `(force?: boolean \| undefined): void` | Checks the value against the validation rules, such as `required` and `behavior="filter"`, and updates `validity` and the error message.<br /><br />**force**: If true, validates even when the combobox has focus or hasn't been used yet.<br />If false, validates only when focus is outside the combobox and it has been used or has a value. |

## Events

| Event                       | Type                                             | Description                                      |
|-----------------------------|--------------------------------------------------|--------------------------------------------------|
| `auroCombobox-valueSet`     | `CustomEvent<any>`                               | Deprecated: Use the `input` event instead, which also includes the new value. Fires whenever `value` changes. |
| `auroFormElement-validated` |                                                  | Fires each time the combobox validates, with the current `validity` and error `message` in `event.detail`. |
| `input`                     | `CustomEvent<{ optionSelected: any; value: any; }>` | Fires whenever `value` changes, with the new `value` and `optionSelected` in `event.detail`. |
| `inputValue`                | `CustomEvent<{ value: string \| undefined; }>`   | Fires when the text in the input changes, with the new text in `event.detail.value`. |

## Slots

| Name                      | Description                                      |
|---------------------------|--------------------------------------------------|
|                           | The `<auro-menu>` that holds the options. {@requiredWhen always} {@category ui} |
| `ariaLabel.bib.close`     | Text screen readers announce for the close button in the fullscreen bib, such as "Close destination list". Defaults to "Close". {@requiredWhen always} {@category a11y} |
| `ariaLabel.input.clear`   | Text screen readers announce for the clear button, such as "Clear destination". The combobox has no default text, so without it the clear button has no accessible name. In the fullscreen bib, the clear button currently uses "Clear Input" instead. {@category a11y} |
| `bib.fullscreen.headline` | Headline shown above the options in the fullscreen bib, such as "Choose a destination". {@requiredWhen always} {@category ui} |
| `displayValue`            | Content shown in the input in place of the selected option's text while the combobox doesn't have focus, such as an icon. Put it inside each `<auro-menuoption>` with `slot="displayValue"`, and the combobox copies the selected option's content here. Works only with the `snowflake` and `emphasized` layouts. {@category ui} |
| `helpText`                | Help text shown below the combobox. An error message replaces it while the combobox is invalid. {@category ui} |
| `label`                   | Label that names the combobox. Screen readers announce it as the name of the input and of the fullscreen dialog. {@requiredWhen always} {@category ui} |
