# auro-combobox

A text field with a list of options that narrows as people type, so they can choose an option or enter their own value, such as a destination airport.

**Key capabilities**
- **Suggestion or filter**: Set `behavior="filter"` to require choosing an option from the menu; the default, `suggestion`, also accepts typed text.
- **Filtering as people type**: Typing always hides options whose text doesn't include the typed text, unless `noFilter` is set.
- **Validation**: Set `required` to require a value, and `setCustomValidity` to change the error message.
- **Fullscreen on small screens**: Set `fullscreenBreakpoint` to choose the largest screen size at which the list opens as a fullscreen dialog.
- **Layouts**: Set `layout` to `classic`, `emphasized`, or `snowflake` to change the overall look.

**Example**

```html
<auro-combobox>
  <span slot="bib.fullscreen.headline">Choose a destination</span>
  <span slot="label">Destination</span>
  <span slot="ariaLabel.input.clear">Clear destination</span>
  <auro-menu>
    <auro-menuoption value="SEA">Seattle</auro-menuoption>
    <auro-menuoption value="LAX">Los Angeles</auro-menuoption>
  </auro-menu>
</auro-combobox>
```

### Events

| Name                      | Description                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| auroFormElement-validated | Fires each time the combobox validates, with the current `validity` and error `message` in `event.detail`.    |
| input                     | Fires whenever `value` changes, with the new `value` and `optionSelected` in `event.detail`.                  |
| inputValue                | Fires when the text in the input changes, with the new text in `event.detail.value`.                          |
| auroCombobox-valueSet     | Deprecated: Use the `input` event instead, which also includes the new value. Fires whenever `value` changes. |

### Slots

| Name                    | Category | Required | Relevant when | Description                                                                                                                                                                                                                                              |
| ----------------------- | -------- | -------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| (default)               | ui       | Yes      |               | The `<auro-menu>` that holds the options.                                                                                                                                                                                                                |
| bib.fullscreen.headline | ui       | Yes      |               | Headline shown above the options in the fullscreen bib, such as "Choose a destination".                                                                                                                                                                  |
| displayValue            | ui       |          |               | Content shown in the input in place of the selected option's text while the combobox doesn't have focus, such as an icon. Put it inside each `<auro-menuoption>` with `slot="displayValue"`, and the combobox copies the selected option's content here. |
| helpText                | ui       |          |               | Help text shown below the combobox. An error message replaces it while the combobox is invalid.                                                                                                                                                          |
| label                   | ui       | Yes      |               | Label that names the combobox. Screen readers announce it as the name of the input and of the fullscreen dialog.                                                                                                                                         |
| optionalLabel           | ui       |          | `!required`   | Text shown after the label when `required` isn't set, such as a translated "(optional)". Defaults to "(optional)".                                                                                                                                       |
| ariaLabel.bib.close     | a11y     | Yes      |               | Text screen readers announce for the close button in the fullscreen bib, such as "Close destination list". Defaults to "Close".                                                                                                                          |
| ariaLabel.input.clear   | a11y     |          |               | Text screen readers announce for the clear button, such as "Clear destination". The combobox has no default text, so without it the clear button has no accessible name. In the fullscreen bib, the clear button currently uses "Clear Input" instead.   |
