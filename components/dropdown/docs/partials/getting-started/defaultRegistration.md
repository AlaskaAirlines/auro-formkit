Import the component to register the custom element:

```js
import '@aurodesignsystem/auro-formkit/auro-dropdown';
```

Then use the element in your HTML:

```html
<auro-dropdown>
  Seattle (SEA) to Anchorage (ANC), departs 8:15 AM
  <div slot="trigger">
    Flight details
  </div>
</auro-dropdown>
```
