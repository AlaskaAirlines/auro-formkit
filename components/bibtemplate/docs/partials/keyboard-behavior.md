      <p>The <code>&lt;auro-bibtemplate&gt;</code> element lays out the content of a dropdown bib. When the bib is shown fullscreen on small screens, its header shows a close button that keyboard users reach in the normal tab order.</p>
      <p>When the fullscreen bib opens, some parent components, such as <code>&lt;auro-select&gt;</code>, call <code>focusCloseButton()</code> to move focus to the close button.</p>
