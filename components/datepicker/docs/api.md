# auro-datepicker

The `auro-datepicker` component provides users with a way to select a date or date range from a calendar popup or fullscreen calendar on mobile.

## Properties

| Property                          | Attribute                         | Modifiers | Type                                             | Default                        | Description                                      |
|-----------------------------------|-----------------------------------|-----------|--------------------------------------------------|--------------------------------|--------------------------------------------------|
| `appearance`                      | `appearance`                      |           | `'default' \| 'inverse'`                         | "'default'"                    | Sets the datepicker's colors for the background it sits on. Use `inverse` on dark backgrounds and `default` on light ones. |
| `autoPlacement`                   | `autoplacement`                   |           | `boolean`                                        | "false"                        | Deprecated: Use `placement` instead.<br />Places the calendar dropdown on whichever side of the input has the most space. The dropdown already flips to the opposite side when it doesn't fit, unless `noFlip` is set. |
| `blackoutDates`                   | `blackoutdates`                   |           | `string[]`                                       | []                             | Sets dates people can't select, such as sold-out days, as ISO date strings (`YYYY-MM-DD`). These dates look unavailable in the calendar, and typing one in fails validation with `customError`.<br />To change the list, assign a new array, such as `el.blackoutDates = [...el.blackoutDates, '2024-12-25']`, because the datepicker doesn't notice changes made in place, such as `push()`. |
| `blackoutLabel`                   | `blackoutlabel`                   |           | `string`                                         | "'unavailable'"                | Sets the text screen readers add to blackout dates, the dates in `blackoutDates`. Set it to explain why people can't choose those dates, such as `sold out`. |

| `calendarGridLabel`               | `calendargridlabel`               |           | `string`                                         | "'Calendar days of the month'" | Sets the name screen readers announce for the calendar's grid of days. Set it to translate the default. |
| `calendarStartDate`               | `calendarstartdate`               |           | `string`                                         | "undefined"                    | Sets the first month the calendar can show, as an ISO date string such as `2025-01-01`. | `hasError`                        |                                   | readonly  | `boolean`                                        |                                | Checks whether the datepicker has a validation error. |
| `inputmode`                       | `inputmode`                       |           | `'none' \| 'text' \| 'decimal' \| 'numeric' \| 'tel' \| 'search' \| 'email' \| 'url'` |                                | Sets which on-screen keyboard phones and tablets show when someone types a date, such as `numeric` for a number pad (the input's `inputmode`). | `minDateObject`                   |                                   | readonly  | `Date \| undefined`                              |                                | Gets `minDate` as a `Date` object, or `undefined` when `minDate` is empty or isn't a valid date. |

## Methods

| Method                           | Type                                       | Description                                      |
|----------------------------------|--------------------------------------------|--------------------------------------------------|
| `clear`                          | `(): void`                                 | Clears the chosen dates, like `resetInputs()`.   |
| `focus`                          | `(focusInput?: string \| undefined): void` | Moves keyboard focus to the start date input, or to the end date input of a range.<br /><br />**focusInput**: The input to focus. Use `endDate` for the end date input of a range, or leave it out for the start date input. |
| `hideBib`                        | `(): void`                                 | Closes the calendar if it's open.                |
| `initializeArchitectureDefaults` | `(): void`                                 |                                                  |
| `reset`                          | `(): void`                                 | Clears the chosen dates and the validation state. |
| `resetInputs`                    | `(): void`                                 | Clears the chosen dates. Unlike `reset()`, the datepicker still counts as used, so the next validation can report a missing date. |
| `resetLayoutClasses`             | `(): void`                                 | Sets the `layout-*` class on the `.wrapper` element to match the current `layout`, such as `layout-classic`. Does nothing when `layout` isn't set or there's no `.wrapper` element. |
| `resetShapeClasses`              | `(): void`                                 | Sets the `shape-*` class on the `.wrapper` element to match the current `shape` and `size`, such as `shape-rounded-lg`, or to `shape-none` when either isn't set. Does nothing when there's no `.wrapper` element. |
| `showBib`                        | `(): void`                                 | Opens the calendar if it's closed.               |
| `updateComponentArchitecture`    | `(): void`                                 | Updates the `layout-*` and `shape-*` classes on the `.wrapper` element. Called whenever `layout`, `shape`, or `size` changes. |
| `validate`                       | `(force?: boolean \| undefined): void`     | Checks the chosen dates and updates `validity` and the error message.<br /><br />**force**: If true, validates even when the datepicker has focus or hasn't been used yet, so an empty required datepicker reports `valueMissing`. If false, validates only when focus is outside the datepicker and it has been used or has a value. |

## Events

| Event                           | Type                                             | Description                                      |
|---------------------------------|--------------------------------------------------|--------------------------------------------------|
| `auroDatePicker-monthChanged`   | `CustomEvent<{ month: any; year: any; numCalendars: any; }>` | Notifies that the visible calendar month(s) have changed. |
| `auroDatePicker-newSlotContent` | `CustomEvent<any>`                               | Notifies the calendar's day cells to copy their `date_YYYY_MM_DD` and `popover_YYYY_MM_DD` slot content again, such as after `blackoutDates` or `referenceDates` changes. The datepicker doesn't currently fire it on its own when slot content is added. |
| `auroDatePicker-toggled`        | `CustomEvent<{ expanded: any; }>`                | Notifies that the calendar dropdown has been opened/closed. |
| `auroFormElement-validated`     | `CustomEvent<{ validity: any; message: any; }>`  | Notifies that the component value(s) have been validated. |
| `input`                         | `CustomEvent<any>`                               | Notifies that the datepicker's value has changed. |

## Slots

| Name                       | Description                                      |
|----------------------------|--------------------------------------------------|
| `ariaLabel.bib.close`      | Text read by screen readers for the close button in the fullscreen calendar, for example "Close calendar". It has no default, so without it the button has no accessible name. {@requiredWhen always} {@category a11y} |
| `ariaLabel.input.clear`    | Text read by screen readers for the clear button, for example "Clear dates". Defaults to "Clear input field", or a Spanish translation when the datepicker has `lang="es"`. {@category a11y} |
| `bib.fullscreen.dateLabel` | Deprecated: Use `bib.fullscreen.fromLabel` instead. Label shown above the start date in the fullscreen calendar. {@category ui} |
| `bib.fullscreen.fromLabel` | Label shown above the start date in the fullscreen calendar, such as "Departure". {@category ui} |
| `bib.fullscreen.headline`  | Headline shown at the top of the fullscreen calendar, such as "Choose travel dates". {@requiredWhen always} {@category ui} |
| `bib.fullscreen.toLabel`   | Label shown above the end date in the fullscreen calendar of a range, such as "Return". {@relevantWhen range} {@category ui} |
| `date_YYYY_MM_DD`          | Content shown under the day number in the calendar for one date, such as a price. Replace `YYYY_MM_DD` with the date, as in `date_2025_04_21`, and add the `highlight` attribute to show the text in the success color. {@category ui} |
| `fromLabel`                | Label for the start date input, or the only input, such as "Departure date". Also gives the calendar dialog its accessible name. {@requiredWhen always} {@category ui} |
| `helpText`                 | Help text shown below the datepicker, such as the date format to use. An error message replaces it while the datepicker is invalid. {@category ui} |
| `label`                    | Label for the whole datepicker in the `snowflake` layout, such as "Travel dates". The `classic` layout doesn't show it. {@category ui} |
| `optionalFromLabel`        | Text shown after the start date input's label when `required` isn't set, in place of "(optional)", such as a translation. {@relevantWhen !required} {@category ui} |
| `optionalToLabel`          | Text shown after the end date input's label when `range` is set and `required` isn't, in place of "(optional)", such as a translation. {@relevantWhen range} {@category ui} |
| `popover_YYYY_MM_DD`       | Content shown in a popover when someone points to a date in the calendar or moves to it with the keyboard, such as seat availability. Replace `YYYY_MM_DD` with the date, as in `popover_2025_04_21`. Screen readers read it with the date. {@category ui} |
| `toLabel`                  | Label for the end date input of a range, such as "Return date". {@relevantWhen range} {@requiredWhen range} {@category ui} |

## CSS Shadow Parts

| Part              | Description                                      |
|-------------------|--------------------------------------------------|
| `accentIcon`      | The calendar icon shown before the inputs in the `snowflake` layout. The `classic` layout hides it and shows the start date input's own calendar icon instead. |
| `calendar`        | The calendar shown in the dropdown.              |
| `calendarWrapper` | The `<div>` in the dropdown that holds the calendar. |
| `dropdown`        | The dropdown that holds the trigger, the calendar, and the help text. |
| `helpText`        | The `<p>` that holds the help text or error message. |
| `helpTextSpan`    | The `<div>` that holds the help text or error message. |
| `input`           | Each date input: one, or two when `range` is set. |
| `inputSection`    | The `<div>` that holds the date inputs.          |
| `mainLabel`       | The `<label>` that holds the `label` slot, rendered only when `layout="snowflake"`. |
| `trigger`         | The `<div>` in the dropdown's trigger that holds the calendar icon, the inputs, and the clear button. |
| `wrapper`         | The `<div>` inside `trigger` that lays out the calendar icon, the inputs, and the clear button or error icon. |
