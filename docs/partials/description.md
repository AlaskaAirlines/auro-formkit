## Description

`auro-formkit` is a collection of web components for building forms.

It's a monorepo that contains these components:

- `auro-checkbox`
    - `auro-checkbox-group`
- `auro-combobox`
- `auro-counter`
    - `auro-counter-group`
- `auro-datepicker`
- `auro-dropdown`
- `auro-form`
- `auro-input`
- `auro-menu`
    - `auro-menuoption`
- `auro-radio`
    - `auro-radio-group`
- `auro-select`
